    📘 Guía de Sintaxis Matemática y Controles

    Este laboratorio evalúa expresiones matemáticas en tiempo real usando un analizador sintáctico construido desde cero. Puedes escribir ecuaciones en función de t (tiempo continuo) o n (tiempo discreto).

    Señales elementales integradas

    u(t) / step(t)
    Escalón unitario: 1 si arg ≥ 0, 0 si arg < 0.
    delta(t) / imp(t)
    Impulso: Kronecker δ[n] en discreto; impulso de Dirac con flecha en continuo.
    r(t) / ramp(t)
    Rampa unitaria: arg si arg ≥ 0, 0 si arg < 0.
    rect(t)
    Pulso rectangular unitario: 1 para |arg| ≤ 0.5, 0 fuera (ancho 1).
    tri(t)
    Pulso triangular: max(0, 1 − |arg|) con soporte en [−1, 1].
    sinc(t)
    Sinc normalizada: sin(π·arg)/(π·arg), con sinc(0) = 1.
    sgn(t)
    Función signo: −1 si arg < 0, 0 si arg = 0, +1 si arg > 0.
    pulse(t, a, b)
    Pulso entre a y b: equivalente a u(t − a) − u(t − b).

    Funciones matemáticas y constantes

    Operadores: +, -, *, /, ^ (potencia, admite multiplicación implícita como 2t o 3sin(pi*t)).

    Funciones: sin, cos, tan, asin, acos, atan, sinh, cosh, tanh, exp, ln (log natural), log (base 10), sqrt, abs, floor, ceil, round, min, max. Constantes: pi, e, tau (2π).

    Convenciones importantes

    • Escalamiento discreto x[a·n + b]: En tiempo discreto, si a·n + b no es entero (por ejemplo expansión temporal x[0.5n]), el resultado es 0 (interpolación por ceros). Si |a| > 1 (diezmado), solo se conservan muestras donde a·n + b ∈ ℤ.
    • Convolución continua: Se calcula numéricamente sobre el soporte configurable [−L, +L] con paso fino, e incorpora de forma analítica los impulsos de Dirac si están presentes.
    • Controles del gráfico: Arrastra para desplazar; rueda del ratón para zoom (Shift + rueda solo eje X, Alt + rueda solo eje Y). En modo Secuencia Discreta puedes activar el lápiz para arrastrar muestras directamente sobre el plano.
